- 时间计算、小数秒、暂停、继续、重置、跳过和时长边界。

- 状态恢复、损坏的偏好设置、时钟变化和测试配置隔离。

- 卡片自绘阴影、透明边距和紧凑模式窗口尺寸。
- 通过普通遮挡窗口检查窗口服务器中的实际顺序：显示卡片、选中其他窗口、再次点击卡片、开启置顶和关闭置顶。每种状态均测试中英文。
- 使用中、隐藏后和设置修改后的环境动效。

自检和实时 UI 测试均替代了系统通知发送和登录项注册操作。
测试不会更改系统通知权限或登录项注册状态。

实时 UI 测试通过菜单栏按钮打开原生控制菜单，检查卡片恢复、前置顺序和保存的窗口模式。
测试驱动将被选窗口放入全局窗口顺序，以模拟真实的前台点击。
独立原生测试程序验证菜单打开时卡片位于前方。
窗口服务器元数据还确认：独立应用保持激活时，卡片也位于该应用窗口前方。
通过桌面交互工具点击卡片后，菜单也能关闭。
这些原生集成检查单独记录，不计入上表测试集总数。

## 待确认范围

**窗口拖动需要实体鼠标复核。**
AppKit 合成事件未能通过窗口服务器移动窗口。
本次两项拖动检查仍为受限。

跨软件和桌面的菜单外点击需要实体鼠标复核。
桌面交互驱动将点击定向发送给所选应用；原生测试程序没有发送全局鼠标输入的系统权限。
本次未更改系统权限。

以下项目也需要单独进行系统测试：

- macOS 权限和专注模式下的实际通知送达。
- 安装到“应用程序”目录后的登录项注册。
- 目标设备上的实体休眠与唤醒。
- 显示器的实体断开与重连。
- VoiceOver 操作和系统辅助功能显示选项。
- Intel 设备，以及 macOS 26.5.1 以外的版本。
- 超出本次采样时段的长时间运行。

最低构建目标不表示已在 macOS 13 上完成测试。
辅助功能检查不代表完整的无障碍合规认证。

## 复现

```sh
bash scripts/test.sh
```

请每次只运行一个 UI 测试进程。中英文 UI 测试共用同一测试偏好设置域。

脚本会创建独立的测试应用，标识为 `local.focuscard.validation`。
实时 UI 测试将计时数据保存到 `focuscard.uitest`。
自检将计时数据保存到 `focuscard.selftest`。
测试应用使用同一编译产物，并为独立应用标识重新签名。

脚本启动 UI 测试前会刷新 Launch Services 注册。
Launch Services 无法启动测试应用时，脚本改为直接运行可执行文件。本次中英文运行均使用此方式。
脚本会在测试应用退出后检查结果文件。
报告按已完成的结果条目计数，包含最后的偏好设置保持检查。
原始 UI JSON 的 total 字段表示计划步骤数；发布报告另记实际完成数量。
存在失败项时，命令返回非零状态。
受限项会明确保留在 JSON 结果中。

## 发布包检查

```sh
bash scripts/package.sh
```

打包脚本要求先提交源码更改。
脚本会构建应用、生成 ZIP 压缩包并检查压缩包。
随后会解压应用，检查签名和解压前后的可执行文件是否一致。
脚本还会在解压后的应用上运行中英文各 188 项自检。
发布附件同时提供构建信息与 SHA-256 校验文件。

发布包自检重复了现有检查，不计入上表中的新增覆盖数量。
